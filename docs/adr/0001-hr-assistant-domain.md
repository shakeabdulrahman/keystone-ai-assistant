# ADR 0001: Business domain: HR / employee assistant

- Status: Accepted
- Date: 2026-10-06

## Context
We need a realistic business domain so tools, RAG and write actions feel like a product rather than a generic chatbot.

## Decision
Build an AI HR assistant for employees: leave, HR requests, onboarding tasks, meetings, and HR policy documents.

## Consequences
Every interviewer understands HR instantly. It gives natural read tools, a natural RAG corpus (policies, handbook, FAQs), natural write actions that need confirmation (apply for leave) and sensitive personal data, which makes security real. All demo data is synthetic.

## Alternatives considered
Facilities/field operations (strong IoT tie-in but needs more explaining).
